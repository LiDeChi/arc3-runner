# ARC3 research map

- `arc3-math/`: original symbolic-transform specifications and plan. Runnable code is in
  `../../packages/arc3-math/`.
- `cognitive-training-framework/`: the cognitive adversarial training framework, schemas,
  curriculum, implementation notes, and original document.
- `../archive/ui-prototypes/`: static interface prototypes retained for design archaeology.

Research code is intentionally isolated from the supported `server/` and `web/` product runtime.

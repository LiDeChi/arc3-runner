# Spec 06 — 可视化界面（frontend/）

Vite + React + TypeScript。目标：**把 agent 的"脑内活动"（假设、想象、惊讶、修正）和对抗博弈全过程变成可见的东西**。四个视图，路由用 react-router，图表用 recharts，棋盘用 Canvas 2D。深浅色都要可读（CSS 变量）。

## 0. 通用

- 顶栏：run 选择器（下拉，GET /runs）+ 运行状态灯 + 暂停/继续按钮 + 四个 Tab。
- 数据层：`useRunStream(runId)` hook——WS 订阅实时事件；历史回放走 REST。所有组件只吃 spec 05 §2 的事件 JSON，不得私自加字段。
- 网格渲染器 `<GridCanvas grid cellSize overlay?>`：调色板见 spec 02 §2；overlay 支持半透明幽灵帧（想象轨迹）与红绿 diff 热力（预测 vs 实际）。64×64 时 cell 自适应 ≥8px，容器内滚动。

## 1. Tab「总览 Dashboard」

三行布局：

```
┌ 指标卡片行：解题率(滑窗20) | 中位步数 | ECE | 高置信错误率 | 当前难度 ┐
├ 曲线区(recharts, x=episode_idx)：solve_rate & difficulty 双轴 / ECE / overconf ┤
└ 最近 episodes 表：#, 游戏缩略图(小GridCanvas), 陷阱标签chips, 结果, 步数, 置信均值 → 点击跳回放 ┘
```

## 2. Tab「对局回放 Episode Viewer」——核心视图

```
┌──────────────┬──────────────────────┬──────────────────┐
│  游戏棋盘      │   Agent 脑内         │   想象 vs 现实      │
│  GridCanvas   │  每动作假设卡片:      │  上:想象幽灵帧序列   │
│  + 按钮hint图标│   A1: T(0,-1) ▓▓▓░ 78%│  (plan.imagined)   │
│  (装饰,可能骗人)│      M_h∘T(0,-1)∘M_h⁻¹ │  下:预测网格 vs 实际 │
│               │      ▓░░░ 13%         │   + diff红绿热力     │
│               │  belief_revision时红闪 │   + conf仪表         │
├──────────────┴──────────────────────┴──────────────────┤
│ 时间轴: ●目标步 ◆实验步(probe) ▲惊讶尖峰 ✖修正事件  + 播放/步进/速度 │
└─────────────────────────────────────────────────────────┘
```

要点：

- **假设卡片**：`hypotheses` 事件的 top3，`math` 字符串等宽字体显示 + 概率条；上一步与本步概率变化用 ↑↓ 小箭头。发生 `belief_revision` 的动作卡片红色闪烁 1s 并显示"旧假设 → 重新枚举"。
- **想象面板**：`plan.imagined_grids` 逐帧半透明叠加在当前棋盘副本上（幽灵轨迹）；`prediction` 与 `outcome` 到来后显示 diff 热力与"预测正确/错误"徽标 + 当步置信度仪表。
- **时间轴**：每步一个点，形状/颜色区分 intent(goal/probe) 与事件(surprise>0.5 尖峰、revision)；拖动即跳转该步（全部由 events 重建，无需后端配合）。
- 直播模式：WS 事件到达自动前进；用户拖动时间轴即进入回放模式，右上角"回到直播"。

## 3. Tab「对抗视图 Generator」

```
┌ 陷阱×效果 热力图：行=陷阱组合(臂), 列=[出场次数, agent胜率, overconf, UCB分] ┐
│   overconf 高→红(还在骗到agent)，低→绿(已免疫)。颜色即课程进度。            │
├ 臂选择时间线：最近50局每局选中的臂 + 得到的 reward 柱状                        │
└ 合成游戏画廊：最近12个游戏缩略图 + 陷阱chips + 难度 + 结果；点击进入该局回放      │
   + 「预览合成」按钮：调 POST /games/preview 手动出一个游戏看看                 │
```

## 4. Tab「校准视图 Calibration」

- 可靠性图（reliability diagram）：10 bin，柱=实际正确率，对角线=理想；数据 GET /calibration。
- ECE 随 episode 演化曲线。
- **高置信错误事件表**：conf>0.8 且错的每一步，列出 episode/step/当时的 MAP 假设 math/所属陷阱；点击直接跳到回放视图那一步——**这是"agent 学会可信度判断"最直接的观察窗口**。

## 6. 验收（M2 部分 + M3/M4 部分）

- M2：跑一局 g03（镜像陷阱）手写游戏，浏览器里能：逐步回放；看到 A1 假设从 `T(0,-1)` 高概率 → 红闪修正 → `M_h∘T(0,-1)∘M_h⁻¹`（或外延等价程序）上位；看到想象幽灵帧与 diff 热力；时间轴能拖动。
- M3：对抗视图热力图与画廊有真实数据并随训练更新；校准视图可从高置信错误行跳转回放。
- M4：总览卡片与曲线齐全；1000 局 run 下回放视图打开 <2s（events 分页拉取）。
